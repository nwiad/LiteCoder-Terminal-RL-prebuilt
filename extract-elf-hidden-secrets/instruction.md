## Finding Hidden Secrets in ELF File

Analyze a suspicious ELF executable to extract hidden encrypted credentials embedded within it. A setup script is provided to generate the binary.

### Setup

Run the setup script to generate the suspicious ELF binary:

```bash
cd /app && bash setup.sh
```

This produces `/app/suspicious_binary`, the ELF file to analyze.

### Technical Requirements

- Environment: Linux with standard reverse engineering tools (strings, objdump, readelf, hexdump, xxd, Python 3, etc.)
- Input file: `/app/suspicious_binary` (ELF 64-bit executable, generated by setup)
- Output file: `/app/output.json`

### Task

1. Analyze the ELF file structure to locate hidden data embedded in the binary (look beyond standard sections and segments).
2. Extract the raw encrypted data blob from the binary.
3. Identify the encryption method and key used.
4. Decrypt the data to recover the plaintext credentials.
5. Write findings to `/app/output.json`.

### Output Format

`/app/output.json` must be a valid JSON object with exactly these fields:

```json
{
  "encryption_method": "<name of the cipher/algorithm used, lowercase>",
  "encryption_key": "<the key used for encryption, as a string>",
  "credentials": [
    {
      "username": "<username>",
      "password": "<password>"
    }
  ]
}
```

- `encryption_method`: A lowercase string identifying the algorithm (e.g., `"xor"`, `"aes-128-ecb"`, `"rc4"`).
- `encryption_key`: The exact key string used for encryption.
- `credentials`: An array of objects, each with `"username"` and `"password"` string fields, in the order they appear in the decrypted data.

All credential entries found in the decrypted data must be included. Do not omit any.
