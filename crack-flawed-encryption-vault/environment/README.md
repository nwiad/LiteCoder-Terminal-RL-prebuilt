# SecureVault Challenge

A junior developer created a "secure" vault system to store sensitive data. The vault has been encrypted using a custom encryption scheme implemented in `encryption_program.py`.

Your goal is to recover the flag stored inside `vault.enc`.

## Files

- `encryption_program.py` — The encryption program source code
- `vault.enc` — The encrypted vault containing the flag

## Rules

- You have full access to the encryption source code
- The flag format is `CTF{...}`

Good luck!
