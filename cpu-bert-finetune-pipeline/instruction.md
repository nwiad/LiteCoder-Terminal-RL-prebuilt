## CPU-Optimized BERT Fine-Tuning Pipeline

Build a complete, CPU-optimized BERT fine-tuning pipeline for binary sentiment classification using Hugging Face Transformers and PyTorch. The pipeline must work entirely on CPU hardware.

### Technical Requirements

- Language: Python 3.x
- Libraries: `torch`, `transformers`, `datasets`
- All scripts must be runnable on CPU-only machines (no CUDA dependency)
- Working directory: `/app`

### Files to Produce

1. `/app/train.py` — Fine-tuning script
2. `/app/inference.py` — Inference script
3. `/app/config.json` — Training configuration
4. `/app/report.json` — Performance report (generated after training)

---

### 1. Training Configuration (`/app/config.json`)

A JSON file containing all training hyperparameters with the following required keys:

| Key | Type | Constraint |
|---|---|---|
| `model_name` | string | Must be a valid HuggingFace BERT model identifier (e.g., `"bert-base-uncased"` or a distilled variant) |
| `max_seq_length` | integer | Between 32 and 512 |
| `batch_size` | integer | Must be a power of 2, between 1 and 64 |
| `learning_rate` | float | Between 1e-6 and 1e-3 |
| `num_epochs` | integer | Between 1 and 10 |
| `warmup_steps` | integer | >= 0 |
| `weight_decay` | float | >= 0.0 and <= 0.5 |
| `device` | string | Must be `"cpu"` |
| `output_dir` | string | Path where trained model artifacts are saved |
| `seed` | integer | For reproducibility |

### 2. Training Script (`/app/train.py`)

The script must:

- Load configuration from `/app/config.json`
- Load the SST-2 dataset from Hugging Face `datasets` library (subset `glue/sst2`)
- Tokenize the dataset using the tokenizer corresponding to `model_name` in config
- Initialize a `BertForSequenceClassification` (or compatible) model with `num_labels=2`
- Force all computation to CPU regardless of hardware availability
- Use Hugging Face `Trainer` API with `TrainingArguments` derived from `config.json`
- Apply the following CPU optimizations in `TrainingArguments`:
  - Disable `fp16` (set to `False`)
  - Set `dataloader_num_workers` to 0 or a small integer
  - Set `no_cuda` to `True`
- After training, evaluate on the SST-2 validation set
- Save the trained model and tokenizer to the directory specified by `output_dir` in config
- Write `/app/report.json` upon completion

### 3. Inference Script (`/app/inference.py`)

The script must:

- Accept input from `/app/input.txt`, where each line is one text sample to classify
- Load the trained model and tokenizer from the `output_dir` path specified in `/app/config.json`
- Classify each input line as either `"positive"` (label 1) or `"negative"` (label 0)
- Run entirely on CPU
- Write results to `/app/output.json` as a JSON array of objects, each with the following structure:

```json
[
  {
    "text": "the original input text",
    "label": "positive",
    "confidence": 0.95
  }
]
```

- `label`: `"positive"` or `"negative"`
- `confidence`: a float between 0.0 and 1.0, representing the probability of the predicted class
- The output array order must match the input line order
- If `/app/input.txt` is empty, write an empty JSON array `[]` to `/app/output.json`

### 4. Performance Report (`/app/report.json`)

Generated by `train.py` after training completes. Must contain:

```json
{
  "model_name": "bert-base-uncased",
  "dataset": "sst2",
  "num_train_samples": 67349,
  "num_eval_samples": 872,
  "eval_accuracy": 0.87,
  "eval_loss": 0.35,
  "training_time_seconds": 3600.5,
  "device": "cpu",
  "num_epochs": 3,
  "batch_size": 16
}
```

Required keys and types:
- `model_name` (string)
- `dataset` (string, must be `"sst2"`)
- `num_train_samples` (integer, > 0)
- `num_eval_samples` (integer, > 0)
- `eval_accuracy` (float, between 0.0 and 1.0)
- `eval_loss` (float, >= 0.0)
- `training_time_seconds` (float, > 0)
- `device` (string, must be `"cpu"`)
- `num_epochs` (integer, matches config)
- `batch_size` (integer, matches config)

### Edge Cases

- `inference.py` must handle an empty `/app/input.txt` gracefully (output `[]`)
- `inference.py` must handle input lines that are blank or whitespace-only by skipping them (do not include them in output)
- All scripts must run without error when no GPU is available
- `train.py` must set a random seed from config for reproducibility before model initialization
