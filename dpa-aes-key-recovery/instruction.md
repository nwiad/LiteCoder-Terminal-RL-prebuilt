## Recover AES Key Byte from Side-Channel Traces

Perform a Differential Power Analysis (DPA) attack on simulated power traces to recover the first byte of a 128-bit AES key.

### Technical Requirements

- Language: Python 3
- Libraries allowed: `numpy` (pre-installed)
- Input files (pre-generated by setup, located in `/app/`):
  - `/app/traces.npy` — NumPy array of shape `(10000, 100)`, dtype `float64`. Each row is a power trace of 100 samples captured during AES encryption.
  - `/app/plaintexts.npy` — NumPy array of shape `(10000, 16)`, dtype `uint8`. Each row is a 16-byte plaintext used for the corresponding trace.
- Output file: `/app/output.json`
- Script entrypoint: `/app/solve.py` (run via `python3 /app/solve.py`)

### Task Description

The traces contain power leakage correlated with the Hamming weight of the AES S-box output for the first key byte. Gaussian noise is added. No ciphertext is provided. You must:

1. Load `traces.npy` and `plaintexts.npy`.
2. For each key-byte guess `k` in 0–255, and for each trace/plaintext pair, compute `HW(S-box(p[0] XOR k))` where `p[0]` is the first plaintext byte and `S-box` is the standard AES S-box.
3. Use a difference-of-means DPA approach: for each guess `k`, partition traces into two groups based on whether the Hamming weight is above or below a threshold, compute the mean trace of each group, and take their difference.
4. The correct key byte is the guess whose differential trace has the largest absolute peak value.

### Output Specification

Write a JSON file to `/app/output.json` with the following structure:

```json
{
  "key_byte_0": "0xHH"
}
```

- `key_byte_0`: a string in the format `"0x"` followed by exactly two lowercase hex characters representing the recovered first key byte (e.g., `"0x3a"`).

### Constraints

- The script must complete within 120 seconds.
- The script must use the standard AES S-box (as defined in FIPS 197).
- The output JSON must be valid and parseable.
- The recovered key byte must exactly match the secret key byte used to generate the traces.
